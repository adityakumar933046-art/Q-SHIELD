# Q-SHIELD Evaluated Security Properties & Invariants

## Invariant Catalog

### INV-01: Signature & Digest Tamper Resistance
- **Property ID**: `INV-01`
- **Description**: A signature or message modified after signing must be detected and rejected during verification.
- **Threat**: Forgery / Message Digest Tampering.
- **Precondition**: Valid QDS signature created for canonical message $M$.
- **Expected Behavior**: Any modification to signature payload or digest results in `REJECT` decision by `VerificationEngine`.
- **Implementation**: `VerificationEngine.verify_signature()` computes statistical error rates against threshold $\eta_v$.
- **Test**: `tests/attacks/test_forgery.py::test_forgery_attack_simulation_blocked`
- **Result**: PASS (10/10 simulated forgery attempts rejected).

### INV-02: Nonce & Session Replay Protection
- **Property ID**: `INV-02`
- **Description**: A replayed nonce or session request must not be processed as a fresh request.
- **Threat**: Nonce Reuse / Request Replay Attack.
- **Precondition**: Nonce $N_1$ registered in Redis / in-memory replay cache within expiration window.
- **Expected Behavior**: Second submission of $N_1$ raises `ReplayDetectedError` and blocks request.
- **Implementation**: `ReplayProtectionService.check_and_record()`.
- **Test**: `tests/security/test_replay.py::test_replay_protection_service`
- **Result**: PASS (Replayed requests blocked).

### INV-03: Role-Based Authorization Enforcement
- **Property ID**: `INV-03`
- **Description**: Users without required RBAC permissions must be denied access to restricted actions.
- **Threat**: Unauthorized Access / Privilege Escalation.
- **Precondition**: User identity missing required role (`VERIFIER` or `ADMIN`).
- **Expected Behavior**: Authorization check fails with `PermissionDeniedError`.
- **Implementation**: `AuthorizationService.authorize()`.
- **Test**: `tests/security/test_authorization.py::test_permission_check`
- **Result**: PASS (Unauthorized actions denied).

### INV-04: Authoritative Backend Control Flow
- **Property ID**: `INV-04`
- **Description**: Frontend client state must never override authoritative backend verification decisions or identity claims.
- **Threat**: Client-Side Security Bypass.
- **Precondition**: Client sends forged header or client-side approval payload.
- **Expected Behavior**: Backend context ignores client assertions and evaluates DB state authoritatively.
- **Implementation**: FastAPI dependencies (`get_current_identity`, `get_db`).
- **Test**: `tests/security/test_authorization.py`
- **Result**: PASS.

### INV-05: Audit Trail Hash Chain Integrity
- **Property ID**: `INV-05`
- **Description**: Tampering with historical security event records must be detected during forensic inspection.
- **Threat**: Log Tampering / Repudiation.
- **Precondition**: Security event logged with SHA-256 checksum incorporating previous record hash.
- **Expected Behavior**: Modification of log fields invalidates hash chain during forensic verification.
- **Implementation**: `AuditLogger` and `ForensicEngine.investigate()`.
- **Test**: `tests/audit/test_forensic.py`
- **Result**: PASS.

### INV-06: Authoritative Verification Decision Source
- **Property ID**: `INV-06`
- **Description**: All signature verification outcomes (`ACCEPT`/`REJECT`) must originate from `DecisionEngine`.
- **Threat**: Decision Forgery.
- **Precondition**: Signature verification API invoked.
- **Expected Behavior**: Response decision matches `VerificationDecision` object generated by `DecisionEngine`.
- **Implementation**: `DecisionEngine.evaluate()`.
- **Test**: `tests/qds/test_verification.py`
- **Result**: PASS.
